# 架构概述

## 设计目标

用 CH582F/CH592F 实现一个低成本的 Stadia 手柄 BLE→USB 适配器。替代 ESP32-S3方案。

核心约束：SRAM 有限（26KB~32KB），放不下通用中间件层，必须走**直通管道**。

## 模块划分

| 模块         | 文件                    | 职责                                                   | 硬件依赖       |
| ------------ | ----------------------- | ------------------------------------------------------ | -------------- |
| 主循环       | `main.c`              | 初始化、全局状态、状态机、流水线调度                   | 无（纯逻辑）   |
| BLE Central  | `stadia_ble.c/h`      | 扫描/连接 Stadia、接收通知、GATT Write 发送震动        | WCH BLE 协议栈 |
| USB 复合设备 | `sinput_usb.c/h`      | USB 枚举为 CDC+HID 复合设备，收发 HID 报告             | WCH USB 控制器 |
| Stadia 协议  | `stadia_protocol.c/h` | 解析 10 字节输入报告、构建震动报文                     | 无（纯算法）   |
| SInput 构建  | `sinput_builder.c/h`  | 构建 64 字节 SInput 报告、功能响应(0x02)、解析震动     | 无（纯算法）   |
| CDC 日志     | `log.c/h`             | 分级日志输出（printf → CDC 环形缓冲 → USB EP2）      | WCH USB 控制器 |
| 按钮         | `button.c/h`          | PB22 按键软件消抖 + 边缘事件检测（20ms 轮询）          | GPIO 寄存器    |
| 平台抽象     | `platform.c/h`        | SysTick 时间戳、芯片唯一 ID、LED 控制(PA8)、延时、复位、看门狗 WWDG (platform_wdog_init/feed) | 芯片寄存器     |

## USB 端点分配

| 端点 | 类型        | 方向       | 用途                               |
| ---- | ----------- | ---------- | ---------------------------------- |
| EP1  | 中断 IN     | 设备→主机 | CDC 通知端点                       |
| EP2  | 批量 IN/OUT | 双向       | CDC 数据端点（日志输出 + 控制）    |
| EP3  | 中断 IN/OUT | 双向       | HID SInput 游戏手柄报告（64 字节） |

## LED 指示

PA8（低电平点亮），主循环中控制：

| 状态                 | 行为     | 间隔  | 条件                            |
| -------------------- | -------- | ----- | ------------------------------- |
| 初始化中             | 蓝色常亮 | —    | `!g_ble_ready` (BLE 栈未就绪) |
| IDLE（未连接未扫描） | 蓝色闪烁 | 500ms | `g_ble_ready == true`         |
| SCANNING             | 蓝色快闪 | 100ms | 正在扫描                        |
| CONNECTED            | 熄灭     | —    | 已连接                          |

注意: 初始化阶段从 `main()` 执行到 `GAP_DEVICE_INIT_DONE_EVENT` 触发，
通常仅持续数十毫秒，但若 BLE 初始化卡住，常亮状态可帮助诊断。

## 关键设计决策

| 决策                   | 理由                       |
| ---------------------- | -------------------------- |
| 直通管道，无 router 层 | SRAM 有限（26KB~32KB），放不下通用路由层 |
| 仅 SInput 输出         | 单一用途设备，不搞模式切换 |
| 仅支持 Stadia          | 不实现通用 BLE HID 降级    |
| 最多 1 个手柄          | 资源限制                   |
| 无持久化存储           | 暂不存配对手柄地址         |
| 无 OTA/Web 配置        | 单一用途设备               |
| 无自动重连             | 按 BOOT 手动触发扫描       |
