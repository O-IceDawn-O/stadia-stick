# 开发板

## SuperMini CH592F

### 规格

| 项目  | 参数                            |
| ----- | ------------------------------- |
| 芯片  | CH592F (QingKe RISC-V4C @60MHz) |
| SRAM  | 26KB                            |
| Flash | 512KB                           |
| BLE   | 5.4 (2Mbps/1Mbps)               |
| USB   | 2.0 全速设备                    |
| 供电  | USB Type-C (5V)                 |
| 尺寸  | ~21x51mm                        |

### 引脚分配

| 引脚 | 功能      | 说明                                                                                  |
| ---- | --------- | ------------------------------------------------------------------------------------- |
| PA8  | LED       | 板载蓝色 LED，高电平点亮（通过 P-MOS 驱动，GPIOA_ResetBits = 亮，GPIOA_SetBits = 灭） |
| PB22 | BOOT 按钮 | 低电平有效（按下=低），启动时用于进入引导加载程序                                     |

调试输出通过 CDC 虚拟串口走 USB（同一根 USB 线既供电又输出日志），无需硬件 UART。

## CH582F 核心板 (QFN28)

CH582F (QFN28 封装) 与 CH592F 共用 PA8 (LED) 和 PB22 (BOOT) 引脚，功能兼容。
仅 SRAM/Flash 容量不同，固件用法一致。

## 按钮

大部分开发板上有两个物理按钮：

| 按钮            | 引脚 | 功能                                                                                    |
| --------------- | ---- | --------------------------------------------------------------------------------------- |
| **RESET** | 复位 | 按一下复位芯片。不能用作 GPIO。                                                         |
| **BOOT**  | PB22 | 启动时按住+插入 USB 进入引导加载程序。启动后可作为普通 GPIO 输入（一键配对功能）。 |

### BOOT 按钮使用

- **烧录时**: 按住 BOOT 上电插入电脑，即可开始烧录
- **运行时**: 按一下 = 清除当前连接，开始扫描 Stadia 手柄

### 上电启动流程

1. 上电 自动运行固件（LED 慢闪 = 空闲状态）
2. 按 BOOT 开始 BLE 扫描（LED 快闪）
3. 发现 Stadia 手柄 自动连接（LED 熄灭）
4. 再次按 BOOT 断开连接，回到扫描状态

## LED 状态指示

| 状态                       | LED 行为             |
| -------------------------- | -------------------- |
| 初始化中（BLE 未就绪）     | 蓝色常亮             |
| IDLE（空闲，未连接未扫描） | 慢闪，500ms 间隔     |
| SCANNING（正在扫描）       | 快闪，100ms 间隔     |
| CONNECTED（已连接）        | 熄灭                 |

## USB 连接

- 使用 USB Type-C 数据线连接电脑，一般的手机充电线即可
- 枚举后显示为复合设备:
  - "Stick (SInput)" 虚拟串口（CDC 日志输出）
  - "Stick (SInput)" HID 游戏手柄 (VID=0x2E8A, PID=0x10C6)
