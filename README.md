## 这玩意儿能干啥

- [X]  BLE 连接 Stadia 手柄，USB 输入电脑
- [X]  按键/摇杆/扳机全部映射为通用 SInput 手柄
- [X]  蓝牙模式下手柄震动
- [X]  电池电量读取，每 60s 绿色日志打印
- [X]  CH582F/CH592F均适配

目前仅在 Windows 11 Steam 上测试过部分游戏，均正常。

**第一次连接需要在 Steam 设置里重新设置设备输入，不然扳机有问题！**

有改键需求，可以用映射软件调整。有更多想法，自行修改源码。

## 不能干啥

- 不支持同时接多个手柄，一次只能连一个 Stadia
- 不支持 Xbox / PS / Switch 等其他蓝牙手柄
- 不是通用蓝牙接收器，专门为 Stadia 做的
- 没有图形配置界面，改配置需要改代码
- 仅测试支持 Windows ，其余系统未知。

## 如何使用

我相信我写得足够明白。如果碰到问题或者有看不懂的，请咨询大模型。

1. **买板子** — 淘宝搜 CH582F 核心板，低至¥8.8 包邮，有88VIP 的可以叠个红包
2. **下固件** — 用我提供的预编译的或者自己 `make`，预编译固件下载在右侧releases里，不会下载的问大模型
3. **装烧录工具** — 下载 [WCHISPTool](https://www.wch.cn/downloads/WCHISPTool_Setup_exe.html)，沁恒官方的
4. **烧录** — 打开 WCHISPTool，选正确的系列/型号，下载接口选 USB，目标程序文件选固件。板子接 C 口线，**按住 BOOT 不松手插电脑**，烧录工具右下角会显示已连接，松手，点下载，2-3 秒完事
5. **重启** — 按一下板子上的 RST
6. **配对** — 手柄同时按Stadia+Y两秒切蓝牙配对模式。板子蓝灯慢闪，按一下 BOOT，灯变快闪，一般很快配对成功，灯灭。没成功就检查手柄是不是在配对模式，再按一次 BOOT，还不行，就按RST重启板子，重启手柄。还不行就把板子拔了再插上。
7. **Steam 设置** — 打开 Steam → 设置 → 控制器，找到手柄 → 详情 → 开始测试。第一次用需要点"设置设备输入"，按指示操作一遍，矫正板机。
8. **后续使用** — 每次板子断电后重连：手柄切配对模式 → 板子插电脑按 BOOT
9. **查看日志和电量** — 下载/tools下的py脚本运行即可，有不懂的问AI
